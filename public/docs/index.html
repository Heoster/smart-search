Introduction

Welcome to the official documentation for **Tillu Smart Search**. Tillu is a high-performance, AI-powered search infrastructure designed to bridge the gap between traditional search engines and the reasoning capabilities of modern Large Language Models.

Pro Tip: Tillu doesn't just return links; it returns structured answers. It is built to be the "eyes and ears" of your AI agents.

Core Capabilities

Tillu orchestrates a complex pipeline of tools to deliver results that are significantly more useful than a standard search API:

  • Aggregated Search: Powered by SearXNG, pulling from Google, Bing, DuckDuckGo, and more.
  • Smart Scraper: Extracts clean content from web pages, stripping out ads and noise.
  • AI Synthesis: Uses Groq Llama 3.3 70B to synthesize multi-source information.
  • JSON Structurer: Normalizes any data into a predictable schema for your app.

API: Unified

GET /api/unified

The primary endpoint. Runs the full pipeline: Search → Scrape → Synthesize → Structure.

Query Parameters

ParameterTypeDefaultDescription
qstring-The search query. Required.
modestringfastfast, full, or search.
categorystringgeneralgeneral, videos, news.
